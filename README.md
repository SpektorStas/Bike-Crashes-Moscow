# Велодорожки и ДТП в Москве

Сравнение числа ДТП с велосипедистами в 2015 и 2025 годах на территориях с нынешними велодорожками и без них. Единица наблюдения — гексагон радиусом 500 м. Отдельно рассматриваются соседние территории: возможное перераспределение ДТП между улицами может быть незаметно в оценке для одних велодорожек.

[HTML-отчёт](report.html) содержит карту, годовую анимацию и оценки разных моделей. Скачайте файл и откройте в браузере; интернет ему не нужен. Карта открывается на Москве в пределах МКАД, а масштаб и положение можно менять. Таблицы сохранены в [results/](results/).

В локальном DiD оценка составляет **+0,076 ДТП на ячейку**, 95%-й интервал — **[−0,017; +0,169]**. Локальная пуассоновская модель даёт **−17% [−39%; +13%]**. Городской DiD в абсолютных числах положителен и статистически значим. Статистически значимого снижения ДТП у соседей не получено. Эти сравнения не устанавливают эффект строительства: даты открытия большинства велодорожек неизвестны, а данных о велопотоке нет.

## Файлы

- `preprocessing.ipynb` — фильтр велосипедных ДТП, дороги OSM, сетка и панель.
- `analysis.R` — основные модели и экспорт оценок; запускает `spillover_analysis.R`.
- `scripts/` — запуск notebook, историческая разметка, вспомогательные расчёты и сборка отчёта.
- `report/` — шаблон HTML, CSS и JavaScript. Итоговый `report.html` включает их внутри.
- `data/` — ручная проверка истории велодорожек и контур МКАД для карты.
- `tests/` — проверки сетки, оценок, пространственных сумм и интерфейса отчёта.

Описание [данных](docs/data.md) и [метода](docs/methodology.md).

## Воспроизведение

Нужны Python 3.11 или 3.12 и R 4.4+. Версии локального расчёта указаны в `requirements-tested.txt` и `results/R_sessionInfo.txt`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
Rscript -e 'install.packages(c("data.table", "fixest", "jsonlite"), repos="https://cloud.r-project.org")'
```

Положите `moskva.geojson` и `bike_lanes_singlepart.geojson` в корень проекта. Формат описан в [docs/data.md](docs/data.md). Сырые выгрузки в репозиторий не включены. Граница Москвы и дороги скачиваются из OSM при первом запуске; затем используется кэш.

Запускайте команды из корня проекта:

```bash
.venv/bin/python scripts/run_preprocessing.py
.venv/bin/python scripts/audit_bike_history.py
Rscript analysis.R
.venv/bin/python scripts/build_report.py
```

Настройки лет, сетки и классов дорог находятся в первой ячейке notebook. Выполненная копия сохраняется в `outputs/preprocessing.executed.ipynb`. Если исходные данные и настройки не менялись, для повторного расчёта достаточно последних двух команд.

Сборка HTML также обновляет небольшие таблицы в `results/`. Исходные данные, кэш OSM, промежуточные файлы и локальные окружения исключены через `.gitignore`.

## Проверки

Без исходных выгрузок:

```bash
.venv/bin/python tests/check_preprocessing.py
Rscript tests/check_analysis.R
```

После полного расчёта добавьте `--with-data` к обеим командам: будут проверены сохранение числа ДТП, ручная формула DiD, шкала PPML и фактические выборки моделей.

Для проверки HTML:

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/check_report.py
```

На macOS проверка также может использовать установленный Google Chrome. Произвольный путь к браузеру задаётся переменной `REPORT_BROWSER`. Скриншоты сохраняются в `outputs/final/screenshots/`. Эти же проверки без исходных данных настроены в GitHub Actions.
